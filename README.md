# Resume (HTML Only) — Ravi Raj

A simple **HTML-only** resume webpage built using **semantic HTML tags**.  
It includes navigation links (internal anchors), structured sections, tables for experience/education, and contact details.

---

## Features

- Semantic layout using:
  - `<header>`, `<main>`, `<section>`, `<article>`, `<address>`, `<footer>`

- Tables with proper structure:
  - `<table>`, `<thead>`, `<tbody>`

  - Email using `mailto:`
  - Phone using `tel:`

---

## Project Structure


> Save your resume HTML code in `index.html`.

---

## How to Run

### Option 1: Open directly
1. Download/clone the project
2. Open `index.html` in any browser (Chrome, Edge, Firefox)

### Option 2: Use VS Code Live Server (recommended)
1. Open the folder in VS Code
2. Install **Live Server** extension
3. Right-click `index.html` → **Open with Live Server**

---

## Sections Included

- **Header**
  - Name 
- **About Me**
- **Skills** (unordered list)
- **Experience** (table)
- **Projects** (each project inside an `<article>`)
- **Education** (table)
- **Contact** (inside `<address>`)
- **Footer** (copyright)
